## 누가 명단에 오르나

**선생님 방에서 `[이번 달 1365 신청하기]` 를 누른 분만** 오릅니다. 신청은 선택입니다.

- 선생님은 **월 1회 버튼 한 번**입니다. 수업마다 누르지 않습니다
- 수업 기록은 입장·퇴장으로 저절로 쌓이므로, 그 달 4회 수업하셨으면 **4행이 자동으로** 채워집니다
- 진도 메모가 그대로 `활동내용` 칸이 됩니다 (비어 있으면 "한국어 기초 회화 지도")
- 한글로 써 오시던 분은 선생님 방에 파일을 올려 두시면 ZIP에 함께 담깁니다

신청을 안 누른 선생님은 관리 화면에서 `신청 안 한 선생님도 보기` 로 확인만 됩니다.
