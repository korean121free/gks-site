# GKS 수업방 — 1단계 배포 순서

`class.html`(수업 화면)이 쓰는 백엔드입니다. 하는 일은 두 가지뿐입니다.

1. **입장 토큰 발급** — 열쇠(API 비밀값)를 브라우저에 두지 않기 위해 필요합니다
2. **끊김 로그 적재** — 6개월 뒤 판단을 숫자로 하기 위해 필요합니다

전부 무료 범위 안에서 돕니다. 아래를 위에서부터 한 번만 하면 됩니다.

---

## 0. 준비 — LiveKit 계정 (5분, 카드 등록 불필요)

1. https://livekit.io 에서 **Build(무료)** 로 가입 — 월 5,000분까지 무료
2. 프로젝트를 만들고 **Settings → Keys** 에서 세 가지를 복사해 둡니다

| 항목 | 생김새 |
|---|---|
| 서버 주소 | `wss://gks-xxxxxx.livekit.cloud` |
| API Key | `API` 로 시작 |
| API Secret | 긴 무작위 문자열 |

> ⚠️ **API Secret은 채팅창에 붙여넣지 마세요.** 터미널에만 입력합니다.

---

## 1. 저장소 두 개 만들기

`worker` 폴더에서 실행합니다.

**① 기록 저장소 (D1)**

```bash
npx wrangler d1 create gks-class-log
```

나온 `database_id` 를 `wrangler.toml` 의 `여기에-database_id-붙여넣기` 자리에 바꿔 넣습니다.

이어서 표를 만듭니다.

```bash
npx wrangler d1 execute gks-class-log --remote --file=./schema.sql
```

**② 사진 저장소 — 지금은 따로 만들 것이 없습니다**

사진은 **D1 안에 함께 담습니다**(`photo_blob` 표). R2를 켜려면 카드 등록이 필요해서, 그 전까지 이렇게 갑니다.

- 한 장에 담을 수 있는 크기가 정해져 있어 **조각으로 나눠** 담고, 보여 줄 때 다시 이어 붙입니다 — 쓰는 쪽에서는 차이가 없습니다
- 사진 주소는 늘 `/photo/get?k=…` 입니다. 나중에 R2를 켜도 **주소가 바뀌지 않습니다**
- D1 무료 저장 공간은 5GB입니다. 증빙용 작은 장은 예전과 같은 크기(수십 KB), 원본은 그 서너 배 정도라 한참 여유가 있습니다 — 실제 크기는 첫 시험 수업 뒤 `photo.bytes` 로 확인하시면 됩니다

나중에 R2를 켜고 싶으면: 대시보드에서 R2를 한 번 켠 뒤 `wr.bat r2 bucket create gks-photos` → `wrangler.toml` 의 `[[r2_buckets]]` 세 줄 주석을 풀고 배포. **그때부터 새 사진만 R2로 가고, 이미 담긴 사진은 D1에서 그대로 나옵니다.**

**③ 이미 돌고 있는 데이터베이스라면**

`schema.sql` 은 처음 만들 때만 씁니다. 나중에 더한 칸·표는 `migrations.sql` 에 날짜순으로 있습니다.

```bash
wr.bat d1 execute gks-class-log --remote --file=./migrations.sql
```

## 2. 비밀값 3개 넣기

한 줄씩 실행하면 값을 물어봅니다. 붙여넣고 Enter.

```bash
npx wrangler secret put LIVEKIT_API_KEY
```

```bash
npx wrangler secret put LIVEKIT_API_SECRET
```

```bash
npx wrangler secret put ADMIN_KEY
```

`ADMIN_KEY` 는 로그를 볼 때 쓰는 아무 비밀번호입니다 (예: `gks-log-2026-여덟자리아무거나`).

---

## 3. 배포

```bash
npx wrangler deploy
```

끝나면 `https://gks-class.<계정이름>.workers.dev` 주소가 나옵니다. 이 주소를 복사해 둡니다.

살아있는지 확인:

```bash
curl https://gks-class.<계정이름>.workers.dev/health
```

`{"ok":true,"configured":true,"db":true,"photos":true,"store":"d1"}` 가 나오면 정상입니다.
`store` 는 사진 알맹이를 어디에 두는지입니다 — `d1`(지금) 또는 `r2`(나중에 켜면).

---

## 4. 주소 채우기 (파일 2개)

`class.html` 맨 위 두 줄:

```js
var LK_URL    = "wss://gks-xxxxxx.livekit.cloud";
var CLASS_API = "https://gks-class.<계정이름>.workers.dev";
```

`my.html` 과 `admin.html` 맨 위 한 줄씩 (둘 다 같은 값):

```js
var CLASS_API = "https://gks-class.<계정이름>.workers.dev";
```

채운 뒤 GitHub에 올리면 Cloudflare Pages가 1~2분 뒤 자동 반영합니다.

## 5. 시험 수업 해보기

두 기기(또는 두 브라우저 창)에서 **같은 `room` 값**으로 들어가면 연결됩니다.

선생님 쪽:
```
https://gks-site-fie.pages.dev/class.html?room=test01&name=김선영&role=teacher&fb=meet.google.com/abc-defg-hij
```

학생 쪽:
```
https://gks-site-fie.pages.dev/class.html?room=test01&name=Linh&role=student
```

| 파라미터 | 뜻 |
|---|---|
| `room` | 수업방 이름 — **두 사람이 같아야** 연결됩니다 |
| `name` | 화면에 보일 이름 |
| `role` | `teacher` 또는 `student` |
| `me` | 본인 전화번호 — **이것이 개인 방의 열쇠입니다.** 없으면 기록이 안 남습니다 |
| `with` | 짝 이름 (기록에 함께 남습니다) |
| `fb` | (선택) 연결이 안 될 때 넘어갈 구글 미트 주소 |

기록까지 확인하려면 `me` 와 `with` 를 넣어 들어가야 합니다.

```
...class.html?room=test01&name=김선영&role=teacher&me=01012345678&with=Nguyễn Linh
```

수업을 마치고 `[나가기]` → 진도 한 줄 → 자동으로 개인 방으로 넘어갑니다.

```
https://gks-site-fie.pages.dev/my.html
```
(전화번호 + **등록된 이름 그대로** 넣으면 열립니다)

**확인할 것**
- 입장 전 점검에서 마이크 막대가 움직이는지
- 서로 얼굴·목소리가 나오는지
- `[교재 보이기]` 로 화면 공유가 되는지
- `[음성 우선]` 을 누르면 영상이 꺼지고 소리만 남는지
- 와이파이를 잠깐 껐다 켜면 **저절로** 다시 붙는지 ← 이게 핵심입니다

## 6. 선생님 방 (`my.html`)

전화번호 + 등록된 이름으로 열립니다. 안에 있는 것:

선생님 화면에는 **1365에 필요한 것만** 둡니다. 원본이니 증빙용이니 하는 말은 나오지 않습니다.

| 칸 | 내용 |
|---|---|
| 누적 숫자 | 수업 횟수 · 쌓인 시간 · 이번 달 |
| **지금 가르치는 학생** | 늘 보입니다. 쉬는 중이면 함께 표시 |
| **파송증 · 프로필 사진** | 눌러서 펼침. 크게 보기 · 내려받기 · 올리기 |
| **함께한 학생 · 매칭표** | 눌러서 펼침. 짝별 첫 수업 ~ 마지막 수업, 횟수, 시간, `현재`/`쉬는 중`/`과거` |
| **사진 보관함** | `수업 증빙` / `자유 사진` 두 칸. 크게 보기 · **내려받기(하나뿐)** · 지우기 · 올리기 |
| 본부에 한마디 | 메시지 / 휴식 신청 + 본부 확인 여부 |
| 지난 수업 | 날짜별 진도 메모 |

**매칭표는 따로 관리하지 않습니다** — 수업 기록에서 저절로 만들어집니다. `현재`는 최근 3주 안에 수업했거나 쉬기로 알려 준 짝입니다.

### 수업 증빙 사진 — 날짜·시간이 새겨집니다

1365는 날짜·시간이 보여야 증빙으로 받아 줍니다. 파일 정보(EXIF)는 담당자가 볼 수 없으니 **이미지 자체에 새깁니다.**

흐름은 **사진관과 같습니다.** 선생님은 잘 나왔는지만 보시면 됩니다.

```
선생님이 수업 중 [사진] 누름
   → 학생 화면에 "선생님이 수업 사진을 남기고 싶어 합니다 — 괜찮습니다 / 지금은 아니요"
   → 학생이 괜찮다고 하면 두 화면에 3 · 2 · 1 → 찰칵
   → 찍은 것이 크게 보이고, 아래에 [다시 찍기] [확인] 둘뿐
   → 마음에 들 때까지 다시 찍음 (찍은 것은 아래 줄에서 골라볼 수 있음, 최대 6장)
   → [확인] 을 누른 한 장만 저장. 나머지는 보내지 않고 그냥 버림
```

저장되는 사진은 두 사람 화면이 나란히 놓이고, 아래 흰 띠에 새겨집니다.

```
2026년 7월 30일 (목) 20:31          글로벌한국어나눔 · 1:1 한국어 튜터링
선생님 김선영  ·  학생 Nguyễn Linh        온라인 수업 · gks-01
```

### 선생님은 한 장만 알면 됩니다

`[확인]` 한 번에 뒤에서 두 장이 만들어집니다. **선생님 화면에는 이 구분이 나오지 않습니다.**

| | 크기 | 어디에 보이나 |
|---|---|---|
| 증빙용 | 1280×572 · 150KB 안팎 | **선생님 방** — 1365에 낼 `[내려받기]` 하나뿐 |
| 원본 | 2560×1144 · 350KB 안팎 | **관리 화면에만** — 나중에 워크숍 영상 만들 때 |

두 장은 글자 한 획까지 같습니다 — 원본을 찍은 뒤 그것을 줄여 증빙용을 만들기 때문입니다.

내려받는 파일 이름은 **한국 시간** 기준입니다 (`김경옥2026.07.31_Linh.jpg`) — 사진에 새겨진 날짜와 어긋나지 않게 하기 위해서입니다.

⚠️ 학생이 답을 안 하면 25초 뒤 스스로 접힙니다. **동의 없이는 어떤 경우에도 저장되지 않습니다.**
⚠️ 찍어 놓고 고르는 동안에는 **아무것도 서버로 가지 않습니다** — 브라우저 안에만 있다가, 고르지 않은 것은 사라집니다.
⚠️ [privacy.html](../privacy.html) 에 사진 촬영·보관·삭제 항목을 추가해야 합니다.

## 7. 주간 현황 보기 — 관리 화면

```
https://gks-site-fie.pages.dev/admin.html
```

관리 비밀번호(`ADMIN_KEY`)를 넣으면 열립니다. 사역자님만 보는 화면이라 영어 번역은 넣지 않았습니다.

| 보이는 것 | 쓰임 |
|---|---|
| 주 요약 (수업·선생님·학생·총 시간) | 한 주가 어땠는지 한눈에 |
| **선생님이 남긴 말** | 확인 안 한 것이 맨 위. 누르면 확인 표시 |
| **쉬는 중** | 선생님이 직접 알려 준 휴식 — 아래 명단에서 자동으로 빠집니다 |
| **이번 주 수업한 짝** | 짝별로 요일·분·진도 메모. 끊김·끝맺음 없음도 표시 |
| **이번 주 아직** | 전에 하던 짝인데 이번 주 기록 없음 → 안부 물을 명단 |
| **3주 넘게 수업 없음** | 이탈 직전 구간 → 먼저 연락할 명단 |
| **그 달 수업 사진** | 원본 모아보기 — 선생님 방에는 안 보입니다. 워크숍 영상 만들 때 쓰시라고 |

`← 지난주` / `다음주 →` 로 지난 주도 볼 수 있습니다.

### 휴식 처리 — 명단을 믿을 수 있게

두 달 쉬기로 한 짝이 "챙길 명단"에 계속 뜨면 그 명단을 아무도 안 봅니다. 그래서 선생님이 직접 알려 줄 수 있게 했습니다.

선생님 개인 방([my.html](../my.html)) → **본부에 한마디** →

- **`할 말 남기기`** — 자유롭게. 월간 리포트에도 함께 실립니다
- **`잠시 쉽니다`** + 복귀 예정 날짜 — 그 기간에는 **챙길 명단에서 빠지고 "쉬는 중"으로** 보입니다

쉬는 이유는 안 적어도 보낼 수 있게 했습니다. 쉬려는 분께 숙제를 드리지 않기 위해서입니다. 복귀 예정일이 지나면 자동으로 쉼이 풀리고, 그 전에 수업에 들어오면 그대로 기록이 다시 쌓입니다.

선생님은 자기가 남긴 말과 **본부가 확인했는지**(확인 전 / 확인함)를 개인 방에서 볼 수 있습니다.

## 8. 월간 리포트 보기

```
https://gks-class.<계정이름>.workers.dev/report?key=<ADMIN_KEY>&month=2026-07
```

`session` 표를 월별로 합치기만 한 것입니다 — **따로 만들거나 입력할 것이 없습니다.**

| 나오는 것 | 쓰임 |
|---|---|
| `summary.lessons` / `teacher_minutes` | 그 달 수업 횟수와 총 시간 → 1365 봉사시간 근거 |
| `summary.teachers` / `students` | 실제로 활동한 선생님·학생 수 |
| `summary.abnormal_end` | 창을 그냥 닫아 끝맺음이 없는 수업 수 |
| `by_pair` | 짝별 수업 횟수·시간 |
| `needs_attention` | 2주 이상 수업이 없는 짝 |
| **`notes`** | **그 달에 선생님들이 남긴 말** — 숫자가 설명하지 못하는 사정 |

## 9. 기술 로그 보기 (연결 품질 진단)

```
https://gks-class.<계정이름>.workers.dev/stats?key=<ADMIN_KEY>&days=30
```

- `by_country` — **베트남(VN)과 한국(KR)의 끊김 횟수 차이**. 회선 문제인지 우리 문제인지 여기서 갈립니다
- `by_event` — 재접속·자동 음성전환·미트 폴백이 몇 번 일어났는지
- `recent_sessions` — 수업별 길이와 재접속 횟수

6개월 뒤 이 숫자로 판단합니다.

| 숫자가 이렇게 나오면 | 판단 |
|---|---|
| 재접속이 수업당 0.5회 미만 | 그대로 유지 |
| VN만 유독 나쁘고 colo가 먼 도시 | 서버 위치 문제 → Cloudflare Realtime 검토 |
| VN·KR 둘 다 나쁨 | 학생 회선 문제 → 음성 우선을 기본값으로 |
| 요금이 부담될 때 | LiveKit 자체 호스팅 (접속 주소 한 줄 교체) |

## 문제가 생길 때

**`wrangler login` 이 안 될 때** — 이 컴퓨터는 보안 프로그램이 터미널의 바깥 연결을 막은 적이 있습니다(GitHub CLI에서 겪은 것과 같은 증상). 두 번 실패하면 브라우저 로그인을 포기하고 API 토큰 방식으로 갑니다.

1. Cloudflare 대시보드 → My Profile → API Tokens → **Create Token** → *Edit Cloudflare Workers* 템플릿
2. 터미널에서:

```bash
$env:CLOUDFLARE_API_TOKEN="붙여넣기"; npx wrangler deploy
```

**입장이 안 될 때** — `/health` 가 `configured:false` 면 2번(비밀값)이 안 들어간 것입니다.

**소리는 되는데 영상이 안 나올 때** — 정상일 수 있습니다. 연결이 약하면 자동으로 영상을 끕니다(화면에 안내가 뜹니다).

- **월간 리포트** (`/report`) — 같은 표를 월별로 합산 + 선생님이 남긴 말

- 연결 품질 로그 (`/stats`)

모든 날짜는 **한국 시간(UTC+9)** 기준입니다. Worker는 UTC로 돌기 때문에, 그대로 두면 한국 새벽 수업이 전날로 기록되어 주간·월간 집계가 어긋납니다.

## 아직 안 한 것

- **녹음** — 결정됨: 선생님이 `[녹음]`을 누르면 **학생 화면에 매번 허용/거절이 뜨고**, 거절하면 녹음하지 않습니다. 브라우저가 음성만 녹음(50분 ≈ 12MB) → R2 저장 → 개인 방에서 다시 듣기. `session.recorded` / `rec_key` 칸은 미리 만들어 두었으므로 표를 고칠 일은 없습니다
  → 개인정보처리방침([privacy.html](../privacy.html))에 녹음·보관 기간 항목을 함께 추가해야 합니다
